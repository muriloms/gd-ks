# 📤 Handoff to Design Team - Workflow Instructions

## Overview

This workflow creates a comprehensive handoff package that gives the Design Team everything they need to create the Game Design Document.

**Time:** 30-45 minutes  
**Difficulty:** Beginner (mostly compilation)  
**Output:** `ideation-handoff.md`

---

## Pre-Handoff Checklist

Before creating the handoff, verify you have:

### Required Documents
- [ ] `concept-brief.md` from Sparky
- [ ] `market-analysis.md` from Marcus
- [ ] `mechanics-exploration.md` from Mira

### Minimum Content
- [ ] Clear game concept and hook
- [ ] Defined target audience
- [ ] Core loop designed
- [ ] Key mechanics identified
- [ ] Scope roughly estimated

---

## Step 1: Document Review

I'll review each document for:

### Completeness
- All sections filled?
- Key questions answered?

### Consistency
- Terminology matches across docs?
- No contradicting information?

### Clarity
- Would someone new understand?
- Are decisions explicit?

---

## Step 2: Gap Identification

Common gaps to check:

### Concept Gaps
- [ ] Hook clearly differentiated
- [ ] Core fantasy defined
- [ ] Emotional goals stated

### Market Gaps
- [ ] Audience specific enough
- [ ] Competition understood
- [ ] Positioning clear

### Mechanics Gaps
- [ ] Core loop complete
- [ ] Systems interact properly
- [ ] Scope is realistic

---

## Step 3: Open Questions Documentation

Every concept has unknowns. We document them:

### Design Questions
Questions for the Design Team to resolve

### Technical Questions
Questions for the Engine Team later

### Business Questions
Questions requiring external input

---

## Step 4: Handoff Package Creation

The `ideation-handoff.md` includes:

### Executive Summary
- One-paragraph concept overview
- Key differentiators
- Target audience

### Concept Foundation
- Core fantasy
- Genre and tone
- Setting overview

### Market Position
- Competitive landscape
- Target positioning
- Pricing direction

### Mechanics Foundation
- Core loop
- Key mechanics list
- Systems overview

### Design Team Brief
- Immediate priorities
- Key decisions needed
- Recommended starting point

### Open Questions
- Categorized by team
- Priority ranked

### Document Links
- References to all ideation documents
