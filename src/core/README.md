# GD-KS Core Module

This directory will contain the core system files:

- `module.yaml` - Core module configuration
- `agents/` - Core agents (gdks-master)
- `workflows/` - Core workflows (workflow-init, workflow-status)
- `tasks/` - Core tasks (workflow.xml engine)
- `config/` - Global configuration files
